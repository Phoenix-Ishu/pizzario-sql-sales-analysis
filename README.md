# Pizzario - SQL Pizza Sales Analysis

## Overview

Pizzario is a SQL-based pizza sales analysis project focused on extracting meaningful business insights from sales data using SQL queries and data analysis techniques.

The project demonstrates the use of:
- Joins
- Aggregate Functions
- Subqueries
- Window Functions
- Group By & Order By
- Business Intelligence Concepts

The analysis is divided into Basic, Intermediate, and Advanced SQL problems to evaluate sales performance, customer ordering behavior, revenue trends, and pizza category performance.

## Business Questions Solved

### Basic Analysis
1. Retrieve the total number of orders placed.
2. Calculate total revenue generated from pizza sales.
3. Identify the highest-priced pizza.
4. Find the most common pizza size ordered.
5. List the top 5 most ordered pizza types.

### Intermediate Analysis
6. Find total quantity of each pizza category ordered.
7. Determine order distribution by hour of the day.
8. Analyze category-wise pizza distribution.
9. Calculate average pizzas ordered per day.

### Advanced Analysis
10. Find top 3 pizza types based on revenue.
11. Calculate percentage contribution of each pizza type.
12. Analyze cumulative revenue over time.
